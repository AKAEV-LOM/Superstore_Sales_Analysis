# 📊 Анализ продаж Superstore

Комплексный анализ розничных продаж, включающий очистку и подготовку данных, исследовательский анализ, SQL-аналитику и создание интерактивной BI-отчётности.

## 🛠️ Стек технологий

- **Python (Pandas)** — очистка данных, предварительная обработка, проверка качества данных и исследовательский анализ.
- **PostgreSQL** — аналитические SQL-запросы, сегментация клиентов, CTE и оконные функции.
- **Power BI** — создание KPI и DAX-мер, визуализация данных и разработка интерактивных дашбордов.

## 📌 О проекте

Цель проекта — проанализировать данные о розничных продажах и выявить ключевые тенденции в выручке, поведении клиентов, эффективности товаров и географическом распределении продаж.

Проект охватывает полный аналитический процесс:

**Исходные данные → Очистка данных → SQL-анализ → Power BI → Бизнес-выводы**

## 🔧 Подготовка данных

Предварительная обработка данных выполнена с использованием Python и Pandas.

Основные этапы:

- Проверена структура датасета и типы данных.
- Столбцы `Order Date` и `Ship Date` преобразованы в формат datetime.
- Проверены пропуски и дубликаты.
- Удалены записи с отсутствующим значением `Postal Code`.
- Созданы дополнительные поля `Year` и `Month` для временного анализа.
- Проведена проверка ключевых метрик после очистки.
- Очищенный датасет экспортирован для дальнейшего анализа в SQL и Power BI.

## 🧮 SQL-анализ

Для аналитической обработки данных использовался PostgreSQL.

Основные направления анализа:

- Расчёт общей выручки.
- Анализ продаж по штатам и категориям.
- Определение топ-10 клиентов по выручке.
- Определение топ-10 товаров по выручке.
- Анализ динамики продаж по месяцам.
- Расчёт среднего чека по клиентским сегментам.
- Расчёт накопительной выручки с использованием оконных функций.
- Сегментация клиентов по частоте покупок.

## 👥 Анализ удержания клиентов

Клиенты были сегментированы на основе количества уникальных заказов:

- **Разовая покупка** — 1 заказ.
- **Повторный клиент** — 2–5 заказов.
- **Лояльный клиент** — 6+ заказов.

## 💡 Бизнес-выводы и рекомендации

### Сезонное планирование

Продажи увеличиваются в **4-м квартале (Q4)**, поэтому рекомендуется заранее увеличить запасы и маркетинговую активность перед праздничным сезоном.

### Technology как драйвер роста

Категория **Technology** является лидером по выручке. Расширение ассортимента и поддержание достаточного уровня запасов в данной категории может создать дополнительные возможности для роста выручки.

### Географическая эффективность

**California и New York** относятся к наиболее сильным рынкам по объёму продаж. Оптимизация распределения запасов и логистики в этих регионах может повысить операционную эффективность.
